# Изменения Aether Android RU

## 2.1.7-ru — исходники и тестовая сборка, 3 октября 2026

- Объединены 21 коммит оригинального Aether с тремя коммитами русской сборки без переписывания истории.
- Сохранены русские ресурсы, настройки языка, переводы расширений и `adjustNothing` для исправления клавиатуры Android.
- Сохранены обновления оригинала, включая Android DocumentsProvider для Alpine, изменения истории сообщений и отображения Markdown.
- Убрана глобальная привязка AAPT2 к пути Termux: обычные сборки используют бинарный файл из Maven.
- Переводы расширений применяются только при выбранном русском языке; исправлены смешанные сообщения Web Access и подписи счётчиков.
- Добавлены проверки языка и переводов Android-расширений; сохранены параметры повторных попыток npm из русской сборки.
- Реализация переводов расширений ограничена Android; изменения нативного iOS из прежнего PR сняты.
- Сборка GitHub Actions работает и в форке без секретов подписи, создавая debug APK.
- Добавлены баннер в стиле закреплённых проектов Leostrange, бейджи, инструкции и документация синхронизации.
- Сохранены английский README оригинала и его китайская версия.
- Собран тестовый APK 2.1.7-ru с отдельным пакетом com.baimoqilin.aether.debug; исправления отправлены в [PR #101](https://github.com/Zhou-Shilin/Aether/pull/101).

## 2.1.6 Russian Android — 2 октября 2026

- Добавлены русская локализация интерфейса и переводы Web Access, MCP Servers и Subagents.
- Исправлено схлопывание чата при открытии клавиатуры Android.
- Опубликован APK и добавлены скриншоты русской сборки.

## Android: уточнение области PR и DNS

- Новый Android PR #101 заменяет закрытые PR #96 и #99; добавлены KDoc к изменённым функциям.
- Alpine обновляет DNS из активной сети Android, включая VPN, перед запуском процессов. Это устраняет использование фиксированных публичных DNS при наличии DNS текущей сети.
- Пользователь сообщил: первый APK входит через подписку ChatGPT, новый выдаёт EAI_AGAIN. Точная причина различия и успешный вход на устройстве ещё не подтверждены.
- Локальная сборка APK, 148 общих тестов и 10 целевых Android-тестов прошли.

## Совместимость клавиатуры Android API 29

- `adjustResize` используется на Android 10 и старше; на Android 11+ сохраняется `adjustNothing` с обработкой IME в Compose.
- Выбор режима выполняется до создания Compose-контента и сохраняет остальные флаги окна.
- Добавлены тесты границы API 29/30, сохранности флагов и повторного применения.
- Проверка визуального поведения на устройствах остаётся необходимой; опубликованный APK не заменён.
